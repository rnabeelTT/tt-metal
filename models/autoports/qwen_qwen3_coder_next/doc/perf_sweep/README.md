# Deployed-bundle latency sweep (Hub revision ef463288, 2026-10-03)

Harness: `~/qwen3-coder-next-bringup/scripts/06-perf-sweep.py` (same as the Qwen3.5-122B and gpt-oss-120b sweeps): random-token prompts of exact length, 256 output tokens pinned (128 for the 128-token row), ignore_eos, streamed, one warm-up per input length, closed loop of N requests over Users slots. TTFT median; TPOT = (E2EL - TTFT) / (output - 1) median; total = output tokens / wall. Chunked prefill is on: in long-prompt concurrency rows the running users pause for other users' 2048-token prefill chunks (the plugin never mixes prefill and decode in one step), which moves waiting time from TTFT into TPOT.
